# CodeAlpha Web Scraping Project

## Project Overview

This project was created as part of my CodeAlpha Data Analytics Internship.

The project uses Python and BeautifulSoup to extract book information from a public website and create a structured dataset for analysis.

## Technologies Used

- Python
- BeautifulSoup
- Pandas
- Requests
- CSV

## Data Collected

The project collects:

- Book Title
- Price
- Rating
- Availability

## Project Files

- `scraper.py` - Python web scraping script
- `books_dataset.csv` - Dataset created from the scraped data

## Output

The scraper successfully collected book information and saved it as a CSV dataset.
